
# algo-ps

C++ and Python solutions for algorithmic programming problems

## Environment

- Ubuntu 24.04.4 LTS
- gcc 13.3.0 with `-std=gnu++17`
- Python 3.12.3

## Organization

The structure of `./sources` follows [QOJ Contest Category](https://qoj.ac/category).

Each solution has been verified on at least one of these online judges:
- [JUNGOL](https://jungol.co.kr/)
- [QOJ](https://qoj.ac/)
- [Baekjoon Online Judge (BOJ)](https://www.acmicpc.net/) (read-only as of 2026 Apr 28)
